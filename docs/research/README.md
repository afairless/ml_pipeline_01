# Research Documents

This directory holds design notes and plans that guide the repository. They
record design decisions and their rationale; they are not the user guide.

For current behavior, see [`README.md`](../../README.md) and
[`docs/ARCHITECTURE.md`](../ARCHITECTURE.md). For agent conventions, see
[`AGENTS.md`](../../AGENTS.md).

- [`plan-extract-generic-ml-pipeline.md`](plan-extract-generic-ml-pipeline.md) —
  specification for the reusable pipeline template: goal and invariants,
  destination layout and vocabulary, module-by-module port plan, demo data
  contract, commit-by-commit plan, testing strategy, definition of done, and
  future extensions.
